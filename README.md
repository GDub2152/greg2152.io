# KC8GW Radio Operations Dashboard

GitHub Pages site for ham radio, QRZ profile links, solar propagation, ADS-B feeder summaries, and Google Drive media.

## Upload to GitHub

1. Download and unzip this package.
2. Copy all files into your local clone of `https://github.com/GDub2152/greg2152.io.git`.
3. Commit and push.
4. In GitHub, enable Pages from the main branch.

## Private ADS-B workflow

Do not expose your Raspberry Pi to the internet. Instead, have the Pi periodically update:

`assets/data/adsb.json`

Only include public-safe summary fields such as aircraft count, messages/sec, max range, and last update time.
